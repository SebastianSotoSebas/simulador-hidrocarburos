# Simulador interactivo de hidrocarburos

**Autor:** Aguirre Maira, Pedraza Lara, Soto Sebastian.

**Nivel educativo:** Educación secundaria (Química).

**Objetivo:** Favorecer el aprendizaje de la nomenclatura y las estructuras de hidrocarburos mediante la construcción interactiva de moléculas a partir de sus nombres, la experimentación libre y la retroalimentación sobre las respuestas.

**Contenido:** Alcanos, alquenos y alquinos acíclicos; cadenas lineales y ramificadas; nomenclatura IUPAC; representación esquelética; enlaces simples, dobles y triples; tetravalencia del carbono y fórmulas moleculares. Incluye un modo desafío con niveles progresivos y un modo de construcción libre.

## Uso

Abrir `index.html` en un navegador web. Para publicarlo con GitHub Pages, colocar estos archivos en la raíz del repositorio y habilitar Pages desde la rama principal y la carpeta raíz (`/`).
